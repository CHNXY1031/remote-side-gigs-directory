# Remote Side Gigs & Freelance Platforms Directory

A production-ready Next.js 14 directory for global remote workers, freelancers and side-hustle seekers.

## Highlights

- 132 real platform listings across 6 opportunity categories
- Live search, category filtering and earning-potential filtering
- 32 statically generated programmatic SEO guides
- FAQPage and WebApplication structured data
- Fixed production origin: https://remote-side-gigs-directory.vercel.app
- Google Search Console verification, sitemap and robots routes
- Responsive dark editorial UI with sponsor placement

## Stack

Next.js 14 App Router, TypeScript, Tailwind CSS, lucide-react, clsx and tailwind-merge.

## Local development

    npm install
    npm run dev

Open http://localhost:3000.

## Validation

    npm run lint
    npm run build

## Editorial note

Compensation ranges are directional estimates, not guarantees. Platform eligibility, workload, fees and payout methods vary by region and can change. Every outbound application URL includes the placeholder query parameter ref=remote-side-gigs-directory; replace it with an approved affiliate identifier only after joining the relevant program.
